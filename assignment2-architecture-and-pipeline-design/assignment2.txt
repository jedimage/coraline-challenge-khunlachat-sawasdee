ข้อที่ 2: การออกแบบ Architecture และ CI/CD Pipeline
โจทย์
สมมติว่าบริษัทต้องการพัฒนาระบบ web application ภายในองค์กรระบบหนึ่ง เพื่อใช้เชื่อม
ต่อกับแหล่งข้อมูลหลายประเภทและแสดงผลผ่านหน้าเว็บ โดยระบบดังกล่าวประกอบด้วยหลาย
service ที่ทํา งานร่วมกัน ทั้งส่วนที่ให้บริการผู้ใช้งานผ่านหน้าเว็บ ส่วนที่ให้บห้ ริการเชื่อมต่อผ่าน API และ
ส่วนที่เป็นป็ งานเบื้องหลังของระบบ (เช่น workflow orchestration service อย่าง Apache Airflow)
อีกทั้งยังต้องรองรับการแยก environment เป็นป็ dev / staging / prod และในบางกรณี ระบบนี้อนี้ าจ
ต้องเชื่อมต่อออกไปยังระบบหรือฐานข้อมูลภายนอก ซึ่งอาจอยู่บน cloud หรือ on-premise
ในการออกแบบ ขอให้คํา นึงถึงทั้งโครงสร้างสถาปัตยกรรมของระบบ แนวทางการ deploy
และ release ในแต่ละ environment รวมถึงการดูแลระบบเมื่อใช้งานจริง
ให้ผู้สมัครออกแบบ architecture และ CI/CD pipeline ที่เหมาะสมสํา หรับการ deploy และ
ดูแลระบบลักษณะนี้
สิ่งที่คาดหวัง
● อธิบายภาพรวมของสถาปัตปั ยกรรมระบบได้อย่างเหมาะสม
● อธิบายแนวทางการแบ่ง environment และการ deploy ทั้ง application และ
infrastructure ในแต่ละ environment
● อธิบายแนวทางการจัดการ configuration, secret และการเชื่อมต่อกับระบบภายนอก
● อธิบายแนวทางการดูแลเสถียรภาพของระบบเมื่อใช้งานจริง ทั้งในด้านการป้องกัน การเฝ้าฝ้
ระวัง และการรับมือเมื่อเกิดปัญหา เช่น monitoring, logging, health check และ alerting
● อธิบายแนวทางการ promote หรือ release ระหว่าง dev / staging / prod
